# 0.3.4

## The game's own wallpapers and floors

Wallpaper & floors has a tab for the game's own, like crops and furniture got in 0.3.2: every base wallpaper and floor,
plus the MoreWalls and MoreFloors sets.

- **New art:** paint over a copy of the game's own tile, or pick an image. It goes into the game's texture at that item's
  own spot, so rooms, the catalogue and its icon all show it, in HD when the art is sharper.
- **Hide from shops:** take it out of the catalogue and every shop; rooms already using it keep it.
- **Put the game's art back** at any time.

## Game paintings, one at a time

The Game paintings tab used to take the whole paintings list to replace or hide one painting, so one player replacing a
painting stopped another from touching any of the others. Each game painting is now held and sent on its own, like the
game's crops, furniture and wallpaper.
